Run

Copy config/template.config and fill in input paths and experiment parameters. Input CSV columns are sample_name,fraction_id,path; each row is one mzML fraction. TMT rows may repeat sample_name for distinct fraction_id values within a plex. For TMT, provide channel_csv in the format required by the TMT child pipeline; its plex_id must match sample_name. LFQ samples may have multiple mzML fractions when all samples share the same fraction IDs and quantitate_ProteomicLFQ.fractionated = true. Set search_ProteomicMSMS.search_engines to any nonempty subset of Comet, Sage, and MSFragger. The default is MSFragger. Multiple engines are combined by validation consensus before quantitation. The MSFragger JAR is required only when MSFragger is selected. It passes the same target-decoy FASTA and decoy prefix to search, validation, and protein quantitation. For ProtLoom validation, set validate_ProteomicPSM.run_protloom = true and provide validate_ProteomicPSM.protloom_project_yaml; add an annotation_id column to the input CSV. ProtLoom sample and annotation IDs come from that CSV.

nextflow run main.nf -c config/my-study.config

Use -profile pines or -profile boutroslab_aws to set the lab's shared CPU and memory limits for the metapipeline and each child. An external profile JSON can be selected with compute_profile and additional_resource_profile_dir. Child process allocations can be tuned through each child namespace.
